# YouTube Shorts

A skill for Claude and ChatGPT that turns one finished long video into a series of shorts for
YouTube Shorts, Reels, TikTok (9:16) or LinkedIn (16:9 or 1:1). Every short is a small
standalone explainer with a beginning and an end, so it works for people who never saw the long
video, and it sends them there at the end.

**What it does**

- Asks a few questions first: platforms, length, how many shorts, caption style, brand colours
  and font, graphics or captions only, sounds, end screen text. Every question has a default, and
  it can save your answers to `shorts-profile.md` so it doesn't ask again
- Reads the transcript and proposes the shorts in a table: title, idea, hook, windows, length.
  You strike and re-order before anything is cut
- Gives every short its own hook, cut from the video itself, and checks that no two shorts open
  the same way
- Cuts only in pauses, joins hook, body and closer in one pass so sound and picture stay in sync,
  and hides each join with a small punch-in zoom
- Reframes to 9:16, 16:9, 1:1 or 4:5
- Burns in word-by-word captions in one of three styles (bold, pill, clean)
- Adds a title card, light sound effects, an optional music bed and a "Watch the full video on
  YouTube" end screen
- With HyperFrames: animated graphics with moving arrows, timed to the words, from seven
  templates
- Builds one short first, shows you a preview and a review sheet, and builds the rest after your
  verdict

It never posts anything. You upload the shorts yourself.

## Use it

**Claude Code** (recommended, the build steps need a terminal): copy the `youtube-shorts` folder
into `.claude/skills/` (or `~/.claude/skills/`) and restart. Then: "Make shorts from
`my-video.mp4`."

**Codex:** put the folder in `~/.codex/skills/` and ask the same.

**Claude** (web, desktop): Settings > Capabilities > switch on **Code execution and file
creation**, then Customize > Skills > **+** > Upload a skill, and upload the folder as a ZIP. In
a chat it can pick the shorts, write the hooks, titles and post text from your transcript. Cutting
and rendering need ffmpeg on your own machine, so do those from Claude Code.

**ChatGPT:** open Skills, upload the folder as a skill. Same as Claude: planning and copy in the
chat, the video work from Codex or Claude Code.

## What it needs

**Always (for cutting and captions):**

- `ffmpeg` and `ffprobe`: macOS `brew install ffmpeg`, Ubuntu `sudo apt install ffmpeg`,
  Windows `winget install ffmpeg`
- Python 3.9+ with Pillow: `python3 -m pip install Pillow`

The captions are drawn with Pillow, so any ffmpeg build works (no libass or drawtext needed).
Check your setup in about a minute, no real video needed:

```bash
python3 youtube-shorts/scripts/selftest.py --out selftest-output
```

It makes a synthetic test video with ffmpeg and runs the whole captions-only path on it.

**A transcript with word timings**, one of:

- HyperFrames (below): `npx hyperframes transcribe video.mp4 --model small.en` (English) or
  `--model small --language xx` for other languages. Runs Whisper locally, free.
- openai-whisper: `python3 -m pip install openai-whisper`, then
  `whisper video.mp4 --model small --word_timestamps True --output_format json`. Free, local.
- An `.srt` or `.vtt` from YouTube Studio. Word times are then estimated, fine for picking
  windows; re-transcribe the cut clip for exact word highlights.

**For animated graphics (optional): HyperFrames.** An open-source framework that renders video
from HTML, by HeyGen ([github.com/heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)).

1. Install Node.js 22 or newer ([nodejs.org](https://nodejs.org)). ffmpeg you already have.
2. Check the CLI: `npx hyperframes --version` (npx downloads it on first use). If a render
   complains about the browser, run `npx hyperframes doctor`.
3. Install its agent skills, which teach your agent how to write and render compositions:
   `npx hyperframes skills` (full set), or without the CLI
   `npx skills add heygen-com/hyperframes --all`. In Claude Code they land in
   `~/.claude/skills/` (`hyperframes`, `hyperframes-cli`, `hyperframes-core`,
   `hyperframes-animation` and more). Restart Claude Code afterwards.

Without HyperFrames the skill still makes complete shorts: captions, a still title card, sounds
and a still end screen.

**No API keys.** Nothing in this skill calls a paid service. Music: bring your own track that you
have the rights to, or leave it out. The sound effects are generated by ffmpeg.

## Good to know

- Start with one short. Your feedback on the first one (caption size, graphics, pace) usually
  applies to all of them.
- Read the captions once before you post. Transcription mishears names and similar-sounding
  words; the skill prints the words as text for you to check, but you know your brand names best.
- 9:16 from a 1080p landscape video crops a narrow slice and upscales it. Use a 4K master if you
  have one, or make 16:9 shorts for LinkedIn.
- Video files get big. Keep them outside a git repo, or ignore `*.mp4` and `*.mov`.
- Each script has `--help`. The whole command sequence is in `references/runbook.md`.
